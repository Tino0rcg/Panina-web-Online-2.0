MANUAL DE USUARIO

Scania Access System — Control de Accesos

Plataforma de Control de Identidad y Seguridad Perimetral

Versión 1.0.0 | Mayo 2026
Desarrollado por ONLINE System

1. Introducción

El Scania Access System es una solución integral diseñada por ONLINE System para automatizar el registro de visitantes y fortalecer la seguridad en las instalaciones de Scania Chile. El sistema permite una operación 100% offline, garantizando continuidad operativa sin dependencia de internet.

1.1 Requerimientos del Sistema

  • Estación Base: PC con Windows 10/11 (Mínimo 8GB RAM).
  • Móvil de Escaneo: Smartphone Samsung con cámara funcional.
  • Red: Ambos equipos deben estar conectados a la misma red Wi-Fi local.
  • Puertos: Los puertos 3000 y 3001 deben estar habilitados en el firewall del PC.
Nota Importante: El sistema NO requiere conexión a internet para funcionar, toda la información se guarda localmente en el PC principal.

2. Inicio del Sistema

Para iniciar la operación diaria, ejecute el script principal ubicado en el escritorio o en la carpeta raíz:

1
Ejecutar INICIAR_SCANIA.bat: Haga doble clic en este archivo. Se abrirán tres ventanas de comando que inician el servidor, el puente móvil y la interfaz gráfica.
2
Esperar Carga: El sistema tardará aproximadamente 10 segundos en estar listo mientras carga la base de datos local.
3
Modo Kiosko: La aplicación se abrirá automáticamente en pantalla completa (Modo Kiosko) para el guardia.

3. Operación de Ingreso

El registro de ingresos es el corazón del sistema. Existen dos métodos principales:

3.1 Escaneo con Celular (Recomendado)

Figura 1: Posición correcta para escaneo de cédula.
  1. En el celular, abra la aplicación de escaneo ONLINE System.
  2. Apunte al código PDF417 (reverso de la cédula).
  3. Al escuchar el pitido, los datos aparecerán automáticamente en la pantalla del PC.
  4. Seleccione el destino (Empresa/Persona) y haga clic en "Registrar Ingreso".

3.2 Ingreso Manual

Si la cédula está dañada o el visitante no es chileno:

  • Haga clic en el campo "RUT" e ingrese el número manualmente.
  • Si el visitante ya ha ingresado antes, el sistema autocompletará su nombre automáticamente.
  • Complete los campos faltantes y guarde el registro.
Visitantes Conflictivos: Si el sistema muestra una alerta roja al ingresar un RUT, el visitante está marcado como conflictivo. Informe de inmediato al supervisor antes de permitir el acceso.

4. Gestión de Salidas

Para registrar la salida de un visitante:

  1. Diríjase a la sección "Visitas Activas".
  2. Localice al visitante en la lista (puede usar el buscador por nombre o RUT).
  3. Haga clic en el botón "Registrar Salida".
  4. El sistema cerrará la sesión y calculará automáticamente el tiempo de permanencia.

5. Reportes y Estadísticas

El módulo de administración permite visualizar la actividad de la planta:

  • Dashboard: Gráficos en tiempo real de ingresos por hora y duración promedio.
  • Historial: Tabla completa con todos los registros históricos. Permite filtrar por fecha, rut o nombre.
  • Exportar Excel: En el historial, haga clic en "Descargar Excel" para obtener un archivo compatible con Microsoft Excel para auditorías.
